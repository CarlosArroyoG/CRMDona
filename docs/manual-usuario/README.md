## Qué puede hacer cada rol

| Acción | Administrador | Coordinador de procuración de fondos | Contador | Solo lectura |
|---|---|---|---|---|
| Consultar donantes, donativos, programas y campañas | Sí | Sí | Sí | Sí |
| Registrar y editar donantes | Sí | Sí | No | No |
| Ver y editar datos fiscales de donantes | Sí | Sí | Sí | No |
| Registrar donativos | Sí | Sí | Sí | No |
| Confirmar o cancelar donativos | Sí | No | Sí | No |
| Crear y editar programas y campañas | Sí | Sí | No | No |
| Eliminar registros sin historial | Sí | No | No | No |
| Exportar donantes y donativos | Sí | Sí | Sí | No |
| Exportar programas y campañas | Sí | Sí | Sí | Sí |
| Consultar la configuración de la organización | Sí | No | Sí | No |
| Editar la configuración de la organización | Sí | No | No | No |
| Usuarios y bitácora | Sí | No | No | No |
| Restablecer la contraseña de otra persona | Sí | No | No | No |
| Cambiar su propia contraseña | Sí | Sí | Sí | Sí |

Si un botón no aparece, es porque tu rol no tiene esa acción.
